# contact

Benji Peng's contact card, served at [benji.renocrypt.com](https://benji.renocrypt.com/).

```sh
npm install
npm run dev      # local server
npm run build    # type-check and write dist/
npm run preview  # serve dist/
```

Built with Vite, TypeScript, and [anime.js](https://animejs.com/). Pushing to
`main` deploys to GitHub Pages.
